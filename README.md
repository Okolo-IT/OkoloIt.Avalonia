# OkoloIt.Avalonia

![.NET Version](https://img.shields.io/badge/.NET-10.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

A family of libraries for Avalonia.

- [Property Panel](docs/property-panel.md)

## 📋 Requirements

- .NET 6.0 SDK+;
- Avalonia 11.3.0+;
- Windows 10/11 or Linux.

## 💻 Development

### Setting up the environment

1. Clone the repository:

```sh
git clone https://github.com/Okolo-IT/OkoloIt.Avalonia.git
cd OkoloIt.Avalonia
```

2. Restore dependencies and verify the build:

```sh
dotnet restore
dotnet build
```
